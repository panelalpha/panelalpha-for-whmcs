# PanelAlpha for WHMCS

PanelAlpha for WHMCS connects your WHMCS to your PanelAlpha panel. WHMCS keeps your clients, orders and invoices. PanelAlpha creates the hosting, the WordPress sites and the customer control panel. When an order is paid, suspended or cancelled in WHMCS, the module does the same in PanelAlpha.

The module has two parts, and both come in the same download:

- the **server module**, which WHMCS uses to create and manage services in PanelAlpha,
- the **addon**, which PanelAlpha uses to read invoices and client details from WHMCS (Direct Billing).

## Getting started

Set the module up in this order. Each page assumes the one before it is done.

1. [Install the module](01-getting-started/install.md): requirements and where the files go.
2. [Connect WHMCS to PanelAlpha](01-getting-started/connect-to-panelalpha.md): add your panel as a server in WHMCS.
3. [Set up Direct Billing](01-getting-started/direct-billing.md): let PanelAlpha show WHMCS invoices and usage. Optional, but needed for trials and usage billing.
4. [Create a product](02-products/products.md): choose the PanelAlpha plan you sell.
